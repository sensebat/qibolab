# Teeth matrix

Generated by `python -m tests.instruments.zi.conformance.teeth` with laboneq 26.4.0, on the whole ZI suite (tests/instruments/zi). Each row injects one driver fault from mutants.py into every test and lists the tests that turn red. `@kills` cases are deselected; the `[driver]` case of each effect test runs on the faulty driver instead.

Fault injection: each fault is a hand-written driver bug with a meaning (swept amplitudes ignored, nested sweeps swapped, delays dropped), patched in for one run; unlike mutation-testing tools such as mutmut, which make automatic mechanical code edits.

Caught by: `assertion` = at least one test fails on an assertion (or a strict xfail no longer holds); `LabOne Q refusal only` = only LabOne Q rejects the experiment; `crash only` = tests fail with other exceptions only. A fault no test turns red is a gap.

Left out because they do not pass on the driver itself: `tests/instruments/zi/conformance/test_effects_sweeps.py::test_nested_drive_sweepers_grid[fault-nested_sweepers_swapped]`, `tests/instruments/zi/test_sweep.py::test_split`.
